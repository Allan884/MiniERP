**MiniERP**
MiniERP is a small ERP application built as a learning project. The main goal is to learn full-stack development by building a complete application step by step, while gaining a better understanding of how the different parts of a software system work together.

The project focuses on practical C# development, business logic, data handling, APIs, and eventually a simple user interface.

**Current Progress**
The initial project setup and the first version of data persistence have been completed. The project is now ready to move on to the API development phase.

Completed:
- C# fundamentals and existing models
- Sales Order process
- Business logic and error handling
- Practical LINQ and C# usage
- First version of data persistence

Next:
- REST API with ASP.NET Core


**Learning Roadmap**
  1. C# fundamentals and completing the existing models
  2. Implementing the Sales Order process
  3. Business logic and error handling
  4. Practical use of LINQ and C#
  5. First version of data persistence
  6. REST API with ASP.NET Core
  7. HTTP, JSON, and Swagger
  8. API testing
  9. Completing an end-to-end MiniERP workflow
  10. First prototype of Excel → ERP / ERP → Excel integration
  11. Building a simple UI
    
The goal is not to build a production-ready ERP system, but to use a realistic project to learn, experiment, and understand the full development process from backend logic to a working application.
